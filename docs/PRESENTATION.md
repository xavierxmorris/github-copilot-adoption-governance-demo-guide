# Eight-slide talk track

Use as a slide outline or speaker notes. Live demos fit **inside** these timeboxes; do not add a second 30-minute slide presentation.

| Slide / clock | Headline | On-screen message | Speaker transition |
|---|---|---|---|
| 1 / 00:00-02:00 | Govern first, then measure, then prove | Approved scope -> controlled workflow -> observable adoption -> retained evidence | "What decision do you need before allowing wider use?" |
| 2 / 02:00-06:00 | Show effective policy, not intended policy | Enterprise -> delegated organization -> licensed identity; repo controls are a separate layer | "Which settings must remain centralized?" |
| 3 / 06:00-10:00 | New models, features and tools need an owner | Explicit decisions vs defaults; approved MCP is more than a registry | "A tool connection introduces credentials and another data path." |
| 4 / 10:00-13:00 | Instructions are guidance; scope is the guardrail | Content exclusions vary by mode; prompts are not permissions; unsupported is not protected | "Now inspect how code execution and review are actually gated." |
| 5 / 13:00-17:00 | An agent PR is an evidence chain | Initiator -> attributed commit -> diff -> checks -> human review; inspect credentials/network limits | "We can govern the workflow without waiting for a live generation." |
| 6 / 17:00-24:00 | Seats, activity and spend answer different questions | Synthetic 6/8 observed-active; 4/6 repeated; separate credit/billing example; no automated removal | "These numbers guide enablement; they do not rank developers or prove ROI." |
| 7 / 24:00-28:00 | No training is not zero retention; audit is not every prompt | Surface-specific processing/retention; conditional regional offering/contract; retained event/artifact evidence | "Which part of the required evidence is still missing?" |
| 8 / 28:00-30:00 | Approve a bounded pilot, not a blanket promise | Named owner, cohort, workflows, safety/quality/cost stops, baseline and review date | "What blocks a safe start, and who owns resolving it?" |

## Five useful phrases

- "This is documented behavior; this other item is configured and tested in this tenant."
- "That control protects this surface, not every client or downstream tool."
- "The dataset is invented; the calculation and limitations are reproducible."
- "That is an adoption signal, not causal productivity or audited savings."
- "We need the actual agreement, region and data path before making that assurance."
